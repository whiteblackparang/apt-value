# apt-value: 아파트 실거래가 기반 시세 예측 및 담보대출 리스크 분석

강남구·서초구 아파트 실거래가 데이터를 기반으로 적정 시세를 예측하고, 실거래가와 예측 시세의 괴리율로 담보대출 리스크 등급을 산정하는 프로젝트

> 데이터 수집 → 품질 검증 → EDA → Feature Engineering → 모델링 → 리스크 스코어링 → SHAP 분석까지 전 과정을 다룹니다.

## 핵심 성과

- 10년치(2016~2025) 실거래가 69,686건 직접 수집 → 해제거래 제외 후 67,743건 분석
- 시세 예측 모델 R² 0.616 (LightGBM) — 단지명·법정동 등 위치 피처 추가로 R² 0.262 → 0.616까지 단계적 개선
- 괴리율 기반 리스크 등급 5단계 체계 구축, 고정 임계값의 모델 편향 문제를 분위수 기준으로 교정
- SHAP 분석으로 단지명이 가격의 1위 설명변수임을 정량적으로 증명, 실제 지역 서열(대치·반포·압구정·청담 프리미엄)과 일치 확인

---

## 문제 정의

담보대출 심사 관점에서 핵심 질문

> **같은 단지·같은 평형인데 왜 어떤 거래는 시세보다 비싸거나 싸게 체결되는가? 이 괴리를 정량화해서 담보대출 리스크 판단에 쓸 수 있는가?**

## 데이터

- **출처**: 국토교통부 아파트 매매 실거래가 상세 자료 (공공데이터포털 Open API)
- **범위**: 서울시 강남구·서초구, 2016년 1월 ~ 2025년 12월 (10년)
- **규모**: 69,686건 수집, 해제거래(2.79%) 제외 후 67,743건 분석에 사용
- **주요 컬럼**: 거래금액, 전용면적, 층, 건축년도, 법정동, 단지명, 거래연월, 해제여부

## 분석 과정

### 1. 데이터 수집 (`notebooks/01_data_collection.ipynb`)
국토교통부 실거래가 상세 API를 법정동코드(강남구 11680, 서초구 11650) × 계약년월 조합으로 반복 호출해 10년치 데이터를 수집

### 2. 데이터 품질 검증 (`notebooks/02_data_quality.ipynb`)
- 해제거래 2.79% 확인, 모델링 시 제외
- `dealingGbn`은 2022년부터, `buyerGbn`/`slerGbn`은 2024년부터 제도적으로 신설된 필드임을 확인(결측 아님)
- 2022년 거래량 급감이 금리 상승기와 일치하는 실제 시장 현상임을 확인

### 3. EDA (`notebooks/03_eda.ipynb`)
5개 가설을 검증했습니다.

| 가설 | 결과 |
|---|---|
| 건축연한이 평당가에 영향을 미칠 것이다 | 20년 이상부터 재건축 기대감으로 우상향, 45~50년 구간 급등 |
| 층수가 평당가에 영향을 미칠 것이다 | 확인됨 |
| 거래시기(계절)에 따라 거래량·가격이 다를 것이다 | 거래량은 6~7월 피크, 평당가는 오히려 2월이 최고 — 거래량과 가격 디커플링 |
| 소형 평형일수록 평당가가 높을 것이다(국평 프리미엄) | 가설과 반대 — 국민평형(40-60㎡)이 최고, 소형(~40㎡)이 오히려 최저 |
| 강남구와 서초구는 가격 수준이 다를 것이다 | 강남구가 대체로 높았으나 2024년 근접, 2025년 재역전 |

### 4. Feature Engineering (`notebooks/04_feature_engineering.ipynb`)
건축연한, 평형대, 분양권 여부, 재건축후보 플래그(건축연한 30년 이상)를 파생 변수로 생성. 단지명은 카테고리 수가 많아 Target Encoding(Train 기간 평균 평당가) 적용, 법정동은 원-핫 인코딩

### 5. 모델링 (`notebooks/05_modeling.ipynb`)
시간 기준 Train(2016~2023) / Test(2024~2025) 분할로 검증. 랜덤 분할이 아닌 시간 분할을 택한 이유는, 같은 단지의 거래가 Train·Test에 섞이면서 성능이 부풀려지는 걸 막기 위함입니다.

| 모델 | MAE | RMSE | R² |
|---|---|---|---|
| Linear Regression | 558.4 | 731.6 | 0.617 |
| Random Forest | 509.5 | 741.2 | 0.607 |
| **LightGBM** | **506.3** | **732.5** | **0.616** |

### 6. 리스크 스코어링 (`notebooks/06_risk_scoring.ipynb`)
실거래가와 예측 시세의 괴리율(%)을 분위수(qcut, 5/15/60/15/5%) 기준으로 5단계 등급화. 고정 임계값(±10%, ±20%) 방식은 시장 전체의 가격 상승 추세로 인한 모델의 계통적 편향에 취약해, 상대적 순위 기반으로 변경

### 7. SHAP 분석 (`notebooks/07_shap_analysis.ipynb`)
단지명(Target Encoding)이 가장 강력한 설명변수로 확인. 대치동·반포동·압구정동·청담동은 가격을 높이는 방향, 방배동·논현동·우면동·자곡동은 낮추는 방향으로 나타나 실제 시장 인식과 일치

## 주요 발견

- **단지명(입지) 정보가 가격의 가장 강력한 설명변수**: 단지명을 Target Encoding으로 추가하자 R²가 0.392에서 0.617로 크게 개선됨
- **가격 상승 추세를 반영해야 예측이 성립**: 거래연도를 피처에서 제외하면 R²가 음수로 떨어짐 — 10년간 2배 이상 오른 시장에서는 시간 정보 자체가 핵심 변수
- **재건축 기대감이 건축연한-가격 관계를 비선형으로 만듦**: 20년 이하 구간은 하락~보합, 45~50년 구간에서 급등
- **평형이 작다고 평당가가 높은 게 아님**: 국민평형(40-60㎡)이 최고가, 소형(~40㎡)은 오히려 최저 — 당초 가설과 반대
- **모델에 Cold Start 한계 존재**: Train 기간(2016~2023)에 거래 이력이 없던 신축 단지는 Target Encoding이 전체 평균으로 대체되어, 실제로는 초고가인 신축 프리미엄을 과소평가함(리스크 등급 상위권 왜곡의 원인 중 하나)

## 한계 및 해석상의 주의점

- Target Encoding은 Train 기간에 존재하지 않던 신축 단지의 프리미엄을 반영하지 못함(Cold Start)
- R² 0.617은 완벽한 시세 예측이 아니라 "괴리율 기반 상대적 리스크 스코어링" 목적에서 해석해야 함 — 브랜드, 조망, 학군 등 정형 데이터화되지 않은 요인은 미반영
- 시간 기준 검증(2024~2025 Test)은 향후 시장 전환기(금리 급변 등)에는 예측력이 떨어질 수 있음
- 리스크 등급은 분위수 기준으로, 시장 전체가 동반 상승·하락하는 경우에는 덜 민감할 수 있음

## 실행 방법

1. `pip install -r requirements.txt`
2. 국토교통부 아파트매매 실거래가 상세 자료 API 서비스키 발급 후, `01_data_collection.ipynb`에 입력
3. 노트북 순차 실행: `01_data_collection` → `02_data_quality` → `03_eda` → `04_feature_engineering` → `05_modeling` → `06_risk_scoring` → `07_shap_analysis`

> 학습된 모델 파일(.pkl)은 용량 문제로 리포지토리에 포함하지 않았습니다. `05_modeling.ipynb`를 재실행하면 동일하게 재현 가능합니다.
